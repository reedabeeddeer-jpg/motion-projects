# Flat Design — 15s motion graphics (Remotion)

فيديو موشن كرافيك بستايل Flat Design، بدون صوت، 1920×1080 (16:9)، 30fps، 15 ثانية.

المشاهد: الفكرة (مصباح) ← التصميم (شاشة وواجهة) ← الإطلاق (صاروخ ومخطط نمو) ← الخاتمة.

```bash
npm i
npm run dev      # Remotion Studio
REMOTION_BROWSER=/path/to/headless_shell npx remotion render FlatDesign ../output/flat-design-15s.mp4 --muted
```

## Grocery — التسوق الغذائي

نفس المواصفات، قصة عن التسوق الغذائي: سلة طازجة ← طلب من التطبيق ← توصيل للبيت ← الخاتمة.

```bash
npx remotion render Grocery ../output/grocery-flat-15s.mp4 --muted
```
