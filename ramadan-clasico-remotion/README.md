# كلاسيكو رمضان × Signal — نسخة Remotion

إعلان حماسي 36.5 ثانية (1920×1080، 30fps) بتعليق صوتي رجالي وموسيقى ومؤثرات.

| الوقت | المشهد | التعليق الصوتي |
|---|---|---|
| 0 – 4.6 ث | Intro: عنوان حركي وأشعة إضاءة وجزيئات | «الليلةُ... ليست كأيِّ ليلة!» |
| 4.6 – 14.6 ث | Clash: دخول الشعارين، اصطدام، VS، «الكلاسيكو»، شريط أخبار «مباشر» | «برشلونة... في مواجهة ريال مدريد! إنه الكلاسيكو! أعظم مواجهة في عالم كرة القدم!» |
| 14.6 – 22 ث | Ramadan: إطار رمضان، فوانيس متوهجة، «رمضان كريم» | «وفي ليالي رمضان المباركة... تجتمع العائلة على شغف واحد.» |
| 22 – 30 ث | Product: المعجون، عدّاد 10X، شارات المزايا، فقاعات | «ومع سيجنال... حماية أقوى لأسنانك، وانتعاش يدوم طوال السهرة!» |
| 30 – 36.5 ث | End: البطاقة الختامية والضربة الأخيرة | «سيجنال... ابتسامة الفوز! رمضان كريم!» |

- التعليق الصوتي: ElevenLabs (صوت «Mohamed – Premium Arabic MSA»، نموذج eleven_v3) في `public/audio/vo/full-take.mp3`، مقسّم إلى جمل (`l1` … `l6b`) توضع على الخط الزمني في `src/RamadanClasico.tsx`.
- الموسيقى: `scripts/music.py` يولّد `public/audio/music.wav` (إيقاع حماسي، ضربات، رايزرات، وقسم شرقي بمقام الحجاز). تنخفض الموسيقى تلقائياً تحت الصوت.
- التوقيتات كلها في `src/timeline.ts`.

```bash
npm i
python3 scripts/music.py
npm run dev                                   # Remotion Studio
npx remotion render RamadanClasico out/ramadan-clasico-remotion.mp4
```

بدون تنزيل Chromium: اضبط `REMOTION_BROWSER` على مسار متصفح headless مثبت مسبقاً.
