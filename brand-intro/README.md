# حَرَكة — Brand Intro (Motion Graphics)

فيديو موشن جرافيك عربي احترافي بدقة 1920×1080، و30 إطاراً في الثانية، ومدته 20 ثانية، مع موسيقى ومؤثرات صوتية مولَّدة برمجياً.

**الفيديو النهائي:** [`out/brand-intro.mp4`](out/brand-intro.mp4)

| الوقت | المشهد |
|---|---|
| 0.0–3.6s | جسيمات تنجذب للمركز ← موجة صدمية ← ظهور الشعار |
| 3.6–8.0s | تايبوغرافي حركي: «الإبداع يبدأ بالحركة» |
| 8.0–12.2s | بطاقات: تصميم · حركة · قصة، مع حلقات دوّارة |
| 12.2–16.4s | إنفوجرافيك وعدّادات: +250 مشروع، 98% رضا، 12 جائزة |
| 16.4–20.0s | الشعار النهائي مع لمعة ضوء والشعار اللفظي |

## الملفات
- `scene.html`: كل الرسوم والحركة (Canvas). افتحه في المتصفح لمعاينة مباشرة.
- `soundtrack.py`: يولّد الموسيقى والمؤثرات (whoosh/impact/riser) متزامنة مع المشاهد.
- `render.js`: يلتقط الإطارات عبر Chromium ويرمّزها بـ ffmpeg (H.264 + AAC).

## إعادة التصيير
```bash
NODE_PATH=$(npm root -g) node render.js            # out/brand-intro.mp4
NODE_PATH=$(npm root -g) node render.js --stills   # لقطات معاينة
```
لتغيير النصوص أو الألوان عدّل `scene.html` (الكائن `C` للألوان، ونصوص كل مشهد داخل الدالة الخاصة به).

الخط: Cairo (رخصة SIL OFL، انظر `fonts/OFL-Cairo.txt`).
